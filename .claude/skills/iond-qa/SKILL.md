# iond-qa

Acceso de Claude Code a una skill del QA Catalyst de IOND. El contenido vive en el repositorio; este archivo solo remite a él.

1. Lee `SKILL.md` (raíz del repositorio) y aplica sus reglas.
2. Lee y sigue:
   - `SKILL.md`

Lee el orquestador y aplica sus reglas (fuente canónica, tres etapas, gates, Announce → Confirm → Act). Luego elige la skill según la tabla de enrutamiento.

Recuerda: ClickUp es de solo lectura, bot-test y los repositorios de desarrollo no se modifican, y el QA firma cada veredicto.
