# iond-release

Acceso de Claude Code a una skill del QA Catalyst de IOND. El contenido vive en el repositorio; este archivo solo remite a él.

1. Lee `SKILL.md` (raíz del repositorio) y aplica sus reglas.
2. Lee y sigue:

   - `skills/release/smoke.md`
   - `skills/release/sanity.md`

   - `skills/release/e2e.md`

   - `skills/release/notes.md`
   - `skills/release/deployment-protocol.md`
   - `skills/release/brief.md`
   - `skills/release/bug-hunt.md`

Elige la skill por el estado de la tarea de Release (ver la sección *Releases* del orquestador) y respeta el calendario semanal.
